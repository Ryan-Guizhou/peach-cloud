# Peach Redis MultiCache Quickstart

English | [中文](README.md)

This module validates the minimal integration of `peach-redis-multicache-starter`. Provide a development Redis instance before running; cache TTL, fallback and consistency remain explicit business decisions.

```bash
mvn -f peach-middleware/peach-redis/peach-redis-multicache-quickstart/pom.xml spring-boot:run -Pdevelopment
```

See the parent [`README.md`](../README.md) for capability boundaries.
