# Peach Redisson DistributedLock Quickstart

English | [中文](README.md)

This module validates `peach-redission-distributedlock-starter`. A distributed lock protects only the smallest critical section and never replaces database uniqueness, transactions or business-state validation.

```bash
mvn -f peach-middleware/peach-redission/peach-redission-distributedlock-quickstart/pom.xml spring-boot:run -Pdevelopment
```
