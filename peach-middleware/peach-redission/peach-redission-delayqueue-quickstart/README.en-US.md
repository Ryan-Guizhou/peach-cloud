# Peach Redisson DelayQueue Quickstart

English | [中文](README.md)

This module validates `peach-redission-delayqueue-starter`. Consumers must handle duplicate delivery, retry, idempotency and backlog; do not treat the queue as Exactly-Once.

```bash
mvn -f peach-middleware/peach-redission/peach-redission-delayqueue-quickstart/pom.xml spring-boot:run -Pdevelopment
```
