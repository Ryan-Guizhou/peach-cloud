# Peach Redisson BloomFilter Quickstart

English | [中文](README.md)

This module validates `peach-redission-bloomfilter-starter`. Bloom filters are probabilistic pre-checks only; a "might exist" result must still be verified against the authoritative data source.

```bash
mvn -f peach-middleware/peach-redission/peach-redission-bloomfilter-quickstart/pom.xml spring-boot:run -Pdevelopment
```
