# Peach Rocket Quickstart

English | [中文](README.md)

This module is the runnable integration entry point for `peach-rocket-starter`. It demonstrates local producer/consumer integration without turning development defaults into production guarantees.

Provide RocketMQ endpoints and credentials through the development environment. See the parent [`README.md`](../README.md) for event routing, idempotency, transaction message, Outbox and Topic-governance boundaries.
