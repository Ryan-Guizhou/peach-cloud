# 常见问题

本站汇总控制台与手册使用中的高频问题。仍无法解决时，请联系管理员并附上 **机构上下文、菜单路径、时间点**（勿贴 token）。

---

## 登录后立即跳回登录页 {#login-loop}

**可能原因**

- Token 过期或 Sa-Token `active-timeout` 触发
- 网关 / `peach-auth` 未启动
- 浏览器缓存了失效会话

**处理步骤**

1. 确认 `18080` 网关与认证服务正常
2. 清除站点本地存储后重新登录
3. 查看网关日志是否有 401 / Sa-Token 校验失败

---

## 菜单加载后为空 {#empty-menu}

**可能原因**

- 当前机构未分配菜单资源
- 角色未绑定或未授权给用户
- 切换机构后会话未刷新

**处理步骤**

1. 管理员在 **角色授权** 中检查目标用户角色
2. 让用户 **切换机构或重新登录**
3. 查 [授权日志](/guide/logs-and-audit) 确认近期是否有权限回收

---

## 切换机构后权限不对 {#context-switch}

切换机构会重新装配权限快照。若页面仍显示旧数据：

1. 返回 **工作台**（`/workspace`）
2. 刷新浏览器
3. 仍异常则 **重新登录**

---

## 有菜单但按钮不可用 {#button-disabled}

通常是 **资源码** 未授权：

1. 在 **角色授权** 中检查按钮 / API 资源
2. 确认 `resourceList` 或 `buttonResourceCodes` 包含对应编码
3. 变更后让用户重新登录

---

## 列表无数据但不应为空 {#empty-list}

除权限外，还需检查 **数据权限（DataScope）**：

1. 打开 **角色授权 → 数据权限** Tab
2. 确认模块 `moduleCode` 与范围类型
3. 保存后切换机构或重新登录

---

## 用户手册提示未登录 {#manual-auth}

| 场景 | 说明 |
| --- | --- |
| 生产同域 | 先在主应用登录，再点右上角「用户手册」 |
| 直接访问 `/manual/` | 未登录会跳转 `/login?redirect=...` |
| 本地 `5174` dev | 默认 `VITE_MANUAL_AUTH_ENABLED=false`，免登录写作 |
| 本地跨端口测鉴权 | `localStorage` 不跨端口；需 nginx 同域或部署到 `/manual/` |

---

## 手册内容与界面对不上 {#doc-outdated}

手册由 Markdown 维护，可能滞后于发版：

1. 查 [更新记录](/changelog/) 是否已描述该变更
2. 文档维护者按 [维护指南](/meta/maintenance) 更新对应 `guide/` 页面
3. 模块尚未覆盖时参考仓库内 `peach-manual/README.md` 待办清单

---

## 如何反馈新问题

1. 在 `peach-manual/faq/index.md` 追加条目（维护者）
2. 或提交工单：现象 + 路径 + 机构 + 时间点（脱敏）

详见 [维护指南 · 更新 FAQ](/meta/maintenance#更新-faq)。
