# 日志与审计

Peach Cloud 在 **中间件与审计** 菜单下提供两类日志，用于排查权限问题与追踪用户操作。

## 授权日志（/auth-log）

记录与 **权限、授权配置** 相关的变更与访问审计（具体字段以界面为准）。

### 适用场景

- 核对某次角色 / 用户授权是否生效
- 追溯谁修改了菜单或数据权限
- 与 [授权与数据权限](/guide/authorization) 配合做变更验证

### 使用建议

1. 按时间范围缩小检索
2. 结合操作类型、操作者、目标对象筛选
3. 变更授权后，在此确认是否产生预期记录

## 操作日志（/operation-log）

记录用户在控制台内的 **业务操作行为**（由 `@UserOperLog` 等机制采集，具体以界面为准）。

### 适用场景

- 审计「谁在何时做了什么」
- 排查误操作或数据变更来源

::: warning 隐私与安全
日志中不应包含密码、完整 token 或敏感报文。若发现异常字段，请反馈研发处理。
:::

## 与运行监控的区别

| 模块 | 路径 | 关注点 |
| --- | --- | --- |
| 授权日志 | `/auth-log` | 权限 / 授权变更 |
| 操作日志 | `/operation-log` | 用户业务操作 |
| 运行监控 | `/runtime-monitor` | 服务运行指标 |

## 排查路径示例

**用户反馈「突然看不到菜单了」：**

```text
1. 确认机构上下文 → 登录与机构上下文
2. 查授权日志 → 近期是否有回收权限
3. 让用户重新登录 → FAQ
4. 仍异常 → 查操作日志 / 联系研发
```
