# 快速开始

欢迎使用 Peach Cloud 控制台。按照下面 5 个步骤，你可以在几分钟内完成首次登录并进入工作台。

## 你将完成什么

- 登录系统
- 选择正确的租户 / 机构
- 进入工作台并理解左侧菜单结构
- 知道遇到问题该查哪里

## 前置条件

| 条件 | 说明 |
| --- | --- |
| 账号 | 管理员已创建并分配角色 |
| 服务 | 网关（默认 `18080`）与 `peach-auth` 已启动 |
| 浏览器 | 推荐 Chrome、Edge、Firefox 最新版 |

## 步骤 1：打开登录页

本地开发环境通常为：

```text
http://localhost:5173/login
```

生产环境使用部署域名下的 `/login`。

## 步骤 2：登录

1. 输入账号与密码
2. 完成滑块验证码
3. 若提示使用默认密码，登录后请前往 **个人中心** 修改

::: info 小提示
勾选「记住登录」后，会话写入 `localStorage`，新开标签页（例如用户手册）也能读取登录态。
:::

## 步骤 3：选择机构上下文

登录后，在页面右上角使用 **选择机构上下文** 下拉框，切换到你要操作的租户 / 机构。

不同机构下的菜单、按钮权限和数据范围可能完全不同。切换成功后，系统会重新装配权限快照。

## 步骤 4：进入工作台

- 默认进入 **工作空间 / 数据总览**（路径 `/workspace`）
- 左侧导航按业务域分组展示（详见 [平台功能概览](/guide/platform-overview)）
- 右上角 **用户手册** 按钮可在新标签打开本站

## 步骤 5：确认权限正常

快速自检：

- [ ] 左侧能看到预期菜单
- [ ] 进入目标页面后按钮状态符合角色
- [ ] 列表数据范围符合机构设定

若任一项不符合，请阅读 [授权与数据权限](/guide/authorization) 或 [常见问题](/faq/)。

## 常见误区

| 现象 | 可能原因 | 建议 |
| --- | --- | --- |
| 登录后立即退出 | Token 过期或网关不可达 | 检查 `18080` 与 auth 服务 |
| 菜单为空 | 当前机构未授权 | 联系管理员或查 [FAQ](/faq/#empty-menu) |
| 切换机构后页面异常 | 动态路由未刷新 | 回工作台重新进入或刷新页面 |
