# 文件与存储

Peach Cloud 文件能力基于统一存储组件（`peach-storage`），控制台提供三类常用入口。

## 功能对照

| 菜单 | 路径 | 适用场景 |
| --- | --- | --- |
| 存储实例 | `/storage-instance` | 配置 OSS / MinIO 等 Provider 实例 |
| 文件管理 | `/file-record` | 查询历史上传记录、元数据 |
| 对象浏览 | `/object-browser` | 按实例浏览桶 / 路径下对象 |

## 典型使用流程

### 实施 / 运维：接入存储

1. 在 **存储实例** 中新增实例，填写 Provider 参数（endpoint、bucket、密钥等由安全配置，不在手册中展开）
2. 确认实例状态可用
3. 业务模块通过文件服务 API 或界面上传

### 业务用户：查找文件

1. 进入 **文件管理**，按时间、名称或业务字段筛选
2. 需要直接浏览对象时，进入 **对象浏览** 选择实例与路径

## 权限说明

上述菜单分别对应权限码（示例）：

- `storageInstance:view`
- `fileRecord:view`
- `objectBrowser:view`

无权限时菜单不可见；有菜单无数据时，还需检查数据权限范围。

## 安全注意

- 不要在截图或工单中粘贴完整签名 URL、密钥或 token
- 删除对象前确认业务侧无引用
- 生产环境存储凭证仅通过配置中心或环境变量注入
