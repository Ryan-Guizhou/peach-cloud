# 工作台与消息

## 工作台（/workspace）

工作台是登录后的默认落地页，主要用途：

- 查看当前用户、机构上下文摘要
- 通过快捷入口进入常用功能
- 从头像菜单进入个人中心或退出登录

### 建议使用方式

1. 切换机构后，先回到工作台确认上下文是否正确
2. 从工作台进入业务菜单，避免在旧页面缓存下操作

## 个人中心（/profile）

可在个人中心维护：

| 项目 | 说明 |
| --- | --- |
| 显示名称 | 界面展示用用户名 |
| 手机号 / 邮箱 | 联系方式 |
| 头像 | 上传新头像或切换历史头像 |

修改资料后无需重新登录；权限变更仍需切换机构或重新登录。

## 消息中心（/message-center）

用于查看和处理站内消息通知（具体字段以界面为准）。

常见场景：

- 系统通知、审批提醒
- 业务事件推送

::: info 提示
控制台 WebSocket 通知与消息中心互补：前者偏实时提醒，后者偏消息列表与管理。
:::

## 右上角常用操作

| 操作 | 位置 | 说明 |
| --- | --- | --- |
| 机构切换 | 顶栏下拉 | 切换租户 / 机构上下文 |
| 用户手册 | 顶栏按钮 | 新标签打开本站 |
| 个人资料 | 用户区域 | 进入 `/profile` |
| 退出 | 顶栏 | 清理会话并返回登录页 |
