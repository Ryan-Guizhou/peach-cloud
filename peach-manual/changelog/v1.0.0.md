# v1.0.0

**发布日期：** 2026-09-02

## 新增

- 用户手册站点 `peach-manual`（VitePress + Markdown，暖色阅读主题）
- 指南 7 篇：快速开始、平台概览、登录上下文、工作台、授权、文件存储、日志审计
- FAQ、Changelog、维护指南、配置说明
- 登录门禁（生产启用 / 开发可关闭）
- 控制台右上角「用户手册」按钮（新标签打开）
- 工程 README：记录已做项、待办与维护流程

## 变更

- 主应用增加 `openPeachManual()` 与会话镜像，支持新标签读取登录态
- 手册 UI 对齐控制台 `console-shell` 设计 token（见 `peach-cloud-front/src/style.css`）

## 修复

- （手册初版，无历史修复项）

## 升级注意

1. 部署时需将 `.vitepress/dist/` 发布到 nginx `/manual/` 路径
2. 生产环境 `VITE_MANUAL_AUTH_ENABLED=true`
3. 手册与主应用必须同域，否则无法共享登录 storage
