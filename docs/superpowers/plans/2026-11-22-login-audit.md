# 登录日志与功能导航实现计划

目标：按已确认方案提供登录成功/失败、验证码失败、锁定、主动登出审计；只读查询；默认保留90天；功能树使用功能列表根和四个业务分类。系统日志与密码校验调整不在范围内。

1. 在 auth entity/service/rest 分层增加日志模型、查询、独立事务写入、请求审计与定时清理。测试租户隔离、未归属事件的平台权限、失败不影响认证和敏感数据排除。
2. 以迁移 SQL 重组功能与菜单父级，保留编码和授权；新增日志表、页面和最小资源权限，修复租户路由关联。执行前验证，执行后检查树与权限，并验证幂等。
3. 增加登录日志列表/详情，接通主动登出接口；保持已有UI风格和权限来源，验证空数据、错误、筛选、详情及窄屏。
4. 执行最小 Maven 测试、真实 MySQL 验证、npm构建、浏览器检查和仓库统一检查；双语说明实际行为、运维步骤和残余风险。

约束：不记录密码、Token、验证码、原始请求和原始 User-Agent。未知租户事件不按客户端租户归属。仅信任显式配置的代理转发地址；默认记录直连对端。日志写入失败告警，不改变认证结果，不承诺故障期间无损。无手工更新/删除API。
