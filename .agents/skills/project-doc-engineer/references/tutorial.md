# Tutorial And Getting Started Pattern

新手文档目标是让读者完成一个真实闭环并建立正确心智模型，不是罗列所有 API。

推荐顺序：

1. 前置条件与版本。
2. 5~10 句以内的模块心智模型。
3. 最小依赖。
4. 最小配置。
5. 一个可以运行的典型用例。
6. 从入口到结果的一次真实调用链（复杂时使用 sequenceDiagram）。
7. 如何验证成功。
8. 常见错误与下一步阅读。

How-to 聚焦单一任务，例如“如何新增 Storage Provider”“如何迁移 ThreadPool 到 Virtual Thread”。不要把多个无关目标塞进一篇教程。
