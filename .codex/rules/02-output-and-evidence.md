# Output And Evidence

本规则用于限制 agent 的输出风格，减少空话、猜测和过度展开。

## Response Shape

- 优先中文输出，除非用户明确要求英文
- 先给结论，再给支撑依据
- 简单问题用短段落回答，不强行展开成大纲
- 复杂问题最多拆成 2 到 3 个高层部分，避免写成冗长 changelog

## Evidence Rules

- 代码结论尽量绑定文件路径、类名、方法名或配置项
- 没有验证过的内容必须明确写成“推断”或“不确定”
- 涉及默认值、自动配置行为、SPI 机制时，只能引用源码、配置类、文档或 skill 中已确认的信息
- 用户看不到命令原始输出时，需要在答复里提炼关键结论，而不是说“命令已运行”

## Prohibited Patterns

- 不要把探索过程原样倾倒给用户
- 不要把工具名、命令名堆成没有判断的流水账
- 不要把仓库里没有实现的能力写成已支持
- 不要复制乱码、构建产物路径、IDE 临时目录作为源码事实
