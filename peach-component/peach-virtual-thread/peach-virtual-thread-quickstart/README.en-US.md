# Peach Virtual Thread Quickstart

English | [中文](README.md)

This module demonstrates the runnable integration of `peach-virtual-thread-starter` for blocking-I/O resource groups. It exists to verify configuration, injection and managed task execution and must not become a production dependency.

See the parent [`README.md`](../README.md) for concurrency, pending capacity, backpressure, cancellation and shutdown semantics.
