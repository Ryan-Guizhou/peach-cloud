# Peach Scheduler Quickstart

English | [中文](README.md)

This module demonstrates the runnable integration of `peach-scheduler-starter` on the execution side. It is only a development reference for handler registration, claim-before-execute and result reporting; production scheduling remains coordinated with the `peach-scheduled` control plane.

See the parent [`README.md`](../README.md) for the execution model, transport and idempotency boundaries.
